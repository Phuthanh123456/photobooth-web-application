# Frame CAP

The active design is the supplied **Frame CAP.png**, copied byte-for-byte from the operator's Downloads folder. Source: 2335x3289 RGBA pixels, 399.9738dpi (PNG's rounded 400dpi metadata). SHA-256: `f25c5f60b8cc632ccaa21200af61ab9327cbf313f7bd4a2e8feb2d6c0216d836`. Its native transparent openings, sticker outlines and antialiasing are retained without color removal or repainting. The old two-page PDF and second preview were removed from active assets; old completed outputs remain intact. There is now one design, TEMPLATE_PAGE=1.

`geometry.json` records eight large transparent openings and a clear contentBox inside each opening, measured in points from the top left. Photo 1 through 4 are mapped top-to-bottom in each column; the columns have different opening sizes/positions. Each contentBox is a maximum-area 3:2 rectangle entirely transparent, with 2 source pixels of clearance from stickers. All photo aspect ratios use contain fitting inside that rectangle, preserving the entire photo without sticker occlusion, stretching or cropping. White space is intentional when necessary.

Both compositors draw a white base, then photos, then the original RGBA artwork on top. `page-1.png` is the original artwork flattened over white for an empty preview. JPG output is 1752x2467 at 300dpi. PDF uses the PNG's declared physical dimensions (420.327531x592.058780pt), embeds the original RGBA artwork above the original JPEG streams, and only recompresses a photo if EXIF orientation needs normalization. Physical printing acceptance remains separate.

To regenerate: install build-time Python dependencies with `python -m pip install Pillow numpy scipy`, then run `python tools/inspect-frame.py`. Import an explicitly selected new source with `--source <path-to-PNG>`. Runtime needs only the committed assets. The importer refuses a source without exactly eight large transparent openings and four openings per column.
